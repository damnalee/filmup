# Hyperframes Composition Brief: FilmUp

## Objective
Create a polished, 20-second launch film for FilmUp, a Lahore cinema discovery app. The result should feel like a crafted product launch rather than a generic SaaS advertisement.

## Output
- Composition directory: `brag-output/composition/`
- Rendered video: `brag-output/brag.mp4`
- Poster: `brag-output/brag.jpg`
- Format: landscape — 1920x1080
- Duration: 20 seconds

## Source Material
- Project root: repository root
- Primary files read: `README.md`, `src/App.tsx`, `src/components/NowShowing.tsx`, `src/components/MoviePanel.tsx`, `src/components/AdvanceBookingSignup.tsx`, `src/services/dataSource.ts`, `src/services/advanceBooking.ts`, `src/index.css`
- Product name: FilmUp
- Strongest claim: find cinemas, real future showtimes and advance-booking alerts in one Lahore-focused experience
- Key UI: captured running application screenshot at `docs/screenshots/filmup-home.jpg`
- Copy that must appear verbatim:
  - `LAHORE. MOVIE NIGHT. SORTED.`
  - `EVERY CINEMA. ONE MAP.`
  - `REAL LISTINGS. REAL SHOWTIMES.`
  - `GET THE HEADS-UP WHEN ADVANCE BOOKING OPENS.`
  - `FIND THE SHOW. FIND THE CINEMA.`

## Creative Direction
- Tone preset: polished
- Direction: premium city-night product film; cinematic but restrained
- Visual look: dark map canvas, warm amber highlights, crisp white typography, subtle depth and clean transitions
- No generic gradients, abstract blobs or fabricated dashboard metrics

## Product accuracy
- Use the real screenshot and real app UI as source material.
- Do not invent cinema counts, movie names, prices, showtime values, booking availability or testimonials.
- Do not show private emails, tokens, API endpoints or database identifiers.
- FilmUp links to external booking providers; it does not sell tickets or reserve seats itself.
- The advance-booking feature requires the user to confirm their email before alerts are sent.

## Storyboard
1. 0–3s: Map reveal and hook.
2. 3–7s: Highlight cinema pins and area discovery.
3. 7–12s: Show movie and future-showtime discovery.
4. 12–17s: Demonstrate the advance-booking alert journey.
5. 17–20s: FilmUp wordmark and tagline.

## Audio
Use licensed or bundled instrumental music only. Add restrained UI accents; no voiceover is required. Fade music cleanly at the end.

## Delivery
- Render MP4 in H.264 with a suitable web bitrate.
- Export a representative poster frame as JPEG.
- Include short share copy in `share-copy.txt`.
